# Kalkulator Python Sederhana

Ini adalah kalkulator sederhana yang dibuat dengan Python. Program ini bisa melakukan operasi penjumlahan, pengurangan, perkalian, dan pembagian.

## Cara Menggunakan
1. Pilih operasi yang diinginkan (penjumlahan, pengurangan, perkalian, atau pembagian).
2. Masukkan dua angka yang akan dihitung.
3. Program akan menampilkan hasilnya.
